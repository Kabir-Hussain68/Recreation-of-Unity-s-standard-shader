# Recreation-of-Unity-s-standard-shader
Learning the basic of Shaders by recreating the Unity standard shader on the built-in render pipeline by following the catlike coding rendering series made with Unity version 2017.1.0f3

Sources:
- https://catlikecoding.com/unity/tutorials/rendering/

Features :
- Support for both Forward and Deferred rendering Modes.
- Support for baked and realtime lighting.
- Supports shadows deffered and forward rendering.
- Custom UI made to look as similar to Unity's as possible.
- Supports Parallax for textures and has a raymarching feature for more detail.
- Supports GPU Instancing to improve performance
